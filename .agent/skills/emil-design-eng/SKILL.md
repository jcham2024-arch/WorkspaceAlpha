# Design Engineering
## Detailed guide
Read [the complete design engineering guide](references/detailed-guide.md) before applying this skill. It contains the pinned upstream procedure and AAS safety boundaries. Read it fully for end-to-end work, or load the relevant sections for a focused request.
## When to Use
Use for requested UI polish, interaction feedback, component craft and motion review or implementation.
## Examples
Illustrative request: "Polish the feedback and transitions in this settings panel." Inspect the project tokens, follow the detailed guide, implement only the requested scope, and verify keyboard access and reduced-motion behavior. This is illustrative, not a measured result.
## Limitations and safety
Project requirements and accessibility take precedence over opinionated defaults. Provide keyboard alternatives to gestures, keep decorative duplicates out of the focus order, verify installed APIs, and limit edits and dependency installation to the authorized task. Device and rendered-behavior checks remain necessary.
