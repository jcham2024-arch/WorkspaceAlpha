# Figures that aren't tables

Read at step 3 when a frame carries numbers or a process. If Anthropic's built-in `dataviz` skill is available, load it for palette validation and anti-patterns.

| The frame must show | Form | Template id in assets/figs.html |
|---|---|---|
| A sequence of things done | vertical timeline, one step struck through / one in accent | `tl` |
| Narrowing from many to few | horizontal ladder bars, dashed boxes for zeros | `fn` |
| One thing radiating into many | hub-and-spoke map | `mp` |
| One headline number | giant number + KPI row | poster frame `p8` |
| Progress toward a goal | thin bar with a single accent fill | series `.prog` |
| Days / streak | 7-column calendar grid, today filled | poster frame `p9` |

Each figure: kicker (small, accent) → one-sentence title that states the conclusion → figure → one handwritten accent note pointing at the key point → source line.
